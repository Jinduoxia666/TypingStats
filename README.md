# TypingStats

简体中文 | [English](README.en.md)

常驻 macOS 菜单栏的本地输入统计工具：自动记录每天打了多少字，并附带剪贴板历史、时间戳转换、固定输入法、launchd 定时任务管理和网络测速等小工具。

键盘统计**只计数、不记录内容**，数据只保存在本机和你自己的 iCloud 云盘。

## 功能

### 输入统计
- **全局计数**：在所有 app 中统计字母和数字按键（终端、微信等自绘界面也支持）；标点、空格、回车、方向键、删除键和自动重复不计入
- **字数估算**：字数 = 按键数 ÷ 平均每字按键数（默认 2.0，可在 1.0–6.0 之间调整；中文拼音一般 2–3，纯英文设 1）
- **菜单栏**：常驻显示今日字数（如 `1.2k`）；点开面板可查看本机 / 其他设备字数、CPU 温度和内存占用
- **今日看板**：今日合计、与昨日对比，按小时 / 近 7 天 / 近 30 天的趋势图，按设备堆叠
- **历史趋势**：7 / 30 / 90 天的柱状图，显示合计和日均
- **应用排行**：今日各 app 的输入量；可排除不想统计的 app
- **iCloud 同步**：多台 Mac 的数据通过 iCloud 云盘合并，默认显示所有设备合计
- **导出**：全部历史导出为 CSV / JSON

### 效率工具
| 工具 | 入口 | 说明 |
|---|---|---|
| 剪贴板历史 | `⌃⌥⌘V` / 主窗口「剪贴板」 | 记录最近 50 条文字和图片；面板中用 `↑↓` 选择、`Return` 粘贴、`1`–`8` 直接粘贴 |
| 时间戳转换 | `⌃⌥⌘T` | 秒 / 毫秒时间戳与标准时间互转；自动读取剪贴板内容；结果直接粘贴回原 app |
| 固定输入法 | 菜单栏面板 / 设置 | 输入法被切走后自动恢复为指定输入法，2 秒内最多恢复一次 |
| 定时任务 | 主窗口「定时任务」 | 查看当前用户的 launchd 任务、调度规则、下次触发时间和日志；可启用、停用或立即执行一次 |
| 网络测速 | 主窗口「更多 → 网络测速」 | 调用 macOS 内置的 `networkQuality`，测试速度、延迟和 RPM |

两个全局快捷键都可以在「设置 → 通用」中重新录制。主窗口页面快捷键为 `⌘1`–`⌘6`。

## 系统要求

- macOS 13 Ventura 或更高版本
- 辅助功能权限（用于按键统计、全局快捷键和自动粘贴）

## 安装

1. 打开 `TypingStats-<版本>.dmg`，把 TypingStats 拖进「应用程序」
2. 启动后点击菜单栏的警告图标，选择「授予权限」
3. 在「系统设置 → 隐私与安全性 → 辅助功能」中打开 TypingStats，无需重启，自动开始计数

> 当前版本使用开发证书签名，未经过公证。在其他 Mac 上首次打开时，可能需要右键选择「打开」，或在「隐私与安全性」中点「仍要打开」。

## 从源码构建

需要 Xcode 15 或更高版本（Swift 5.9）。

```bash
make build       # swift build -c release
make app         # 生成并签名 .build/TypingStats.app
make run         # 构建并启动（会先结束正在运行的实例）
make test        # 运行测试
make dmg         # 生成 .build/TypingStats-<版本>-<时间戳>.dmg
make reset-perm  # 重置辅助功能授权
```

默认使用 ad-hoc 签名，每次重新构建后可能需要重新授权辅助功能。想用固定的证书签名、让授权在重新构建后保留，可以在项目根目录新建 `signing.local.mk`（已加入 `.gitignore`，不会提交）：

```make
SIGN_ID := Apple Development: 你的证书名称 (TEAMID)
```

也可以临时指定：`make app SIGN_ID="…"`。用 `security find-identity -v -p codesigning` 查看本机可用的证书。

## 隐私

- 键盘统计只判断按键是否为字母或数字，然后计数，不保存按了哪个键、打了什么内容
- App 不访问任何服务器。只有 iCloud 云盘同步统计快照、以及你手动测速时，才会产生网络流量
- 剪贴板历史会保存复制过的原文和图片，只存在本机，不参与同步，可随时清空

## 数据位置

| 内容 | 路径 |
|---|---|
| 统计数据库 | `~/Library/Application Support/TypingStats/typingstats.sqlite` |
| 剪贴板历史 | `~/Library/Application Support/TypingStats/clipboard-history.json`、`ClipboardImages/` |
| 同步快照 | `~/Library/Mobile Documents/com~apple~CloudDocs/TypingStats/<设备ID>.json` |

## 已知限制

- 字数是按系数估算的：中英混合输入、联想上屏、五笔 / 双拼等情况会有偏差
- 粘贴、语音输入、手写输入不计入
- iCloud 同步有几秒到几分钟的延迟

更完整的需求和设计说明见 [需求说明书](需求说明书.md)。
